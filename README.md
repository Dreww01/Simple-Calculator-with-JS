# 🧮 JavaScript Calculator
A sleek, functional calculator built using HTML, CSS, and JavaScript.
Includes all basic arithmetic operations, a responsive layout, light/dark mode, and history tracking for the last 20 results.

---

🚀 Features
---

✅ Perform addition, subtraction, multiplication, and division

✅ Clear and backspace functionality

✅ Supports decimals and percentages

✅ Responsive, mobile-friendly design

✅ Toggle between light and dark modes 🌙☀️

✅ Stores the last 20 calculations in a scrollable history panel

▶️ Usage
---

Clone or download the project.

Open index.html in your browser.

Start calculating!

Click buttons to build your expression.

Press = to evaluate.

View past 20 results in the History panel.

---
📌 History Feature
---

The calculator saves and displays your last 20 expressions and results.

The history auto-updates with each calculation.

Entries are shown in order from most recent to oldest.
